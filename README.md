# Climate Roots Chapter Expansion Website

A website for Climate Roots' high school chapter program: what a chapter is, how to start one, the project library chapters can pull from, and the expectations chapters are held to once active.

## Pages

- **Home** — mission and vision, core values, last year's highlights, and a 6-step "how to get started" flow
- **Project Library** — starter project ideas (school/community gardens, climate competitions, workshops, fundraisers)
- **Chapter Expectations** — reporting requirements, key requirements, and the three chapter levels (Seedling, Plant, Tree)
- **Chapter Application** — a basic application form

## Tech stack

- React 19 + TypeScript
- Vite
- React Router (`HashRouter`, so routes render as `/#/projects` etc.)
- Tailwind CSS v4
- lucide-react for icons

## Running locally

```bash
npm install --legacy-peer-deps
npm run dev
```

Opens at `http://localhost:5173`.
